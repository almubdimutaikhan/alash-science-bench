    2 · From a book to a defensible label

    Six decisions behind each row

    1. Find a candidate. Excel supplies a search lead. Its modern definition is an annotation, not automatically an authoritative historical fact.
    2. Read the source. Verify the term in the actual OCR page and its surrounding explanation. Keep original author, translator, collected edition and original work distinct.
    3. Choose one target. Decide whether the question asks for a historical name, a modern concept, a scientific explanation or an author's argument.
    4. Write both formats. Keep the stem and target fixed. The MCQ adds alternatives; the short-answer version omits them.
    5. Challenge the answer. A different agent checks support and distractors. Independent human review is a separate stage.
    6. Validate the export. Check exact evidence, keys, field quotas, source pointers, review records and CSV round-trip integrity.

    Provenance means the evidence trail behind an answer. Our row stores the OCR file, actual page ID, printed footer, original excerpt and a page hash. Python character offsets let us check page[start:end] == passage. A hash detects a changed file; it does not make a label true.

    A gold label is a trusted reference for evaluation. Our current reference answers are source-checked by agents but await human and scan verification. Review status makes that distinction visible.

    A real leakage correction

    The draft asked which science Жұмабаев calls «тәрбие пәні», while naming the book «Педагогика» in the question. The book title supplied the answer.

    A real evidence correction

    A farming question asked about alternating a cropping year with a fallow year. The first excerpt started after the defining sentence.

    The reviewer expanded the exact source excerpt so the answer was supported inside the saved evidence itself.

    All 160 pairs received independent agent review. 44 records were revised, including wording, evidence, provenance, acceptable variants and distractors. A revision count is a record of work, not a numerical estimate of remaining error.

    Distractors are the incorrect alternatives. Good ones are plausible answers of the same type. For an anatomical term, other anatomical structures are useful alternatives. A planet, a poem and a farm tool would make the question easy for the wrong reason.

    Historical statements also need careful framing. “What does the author describe?” tests fidelity to that source. “What is scientifically correct today?” requires separate modern evidence and expertise. We preserve historical wording without presenting every historical description as current consensus.

    4 · Design before running

    Four conditions, separate scores

    FormatNo passageWith passage
    Short answerUnassisted recall or explanationSource-supported generation
    MCQRecognition among alternativesSource-supported selection

    Construct validity asks whether the task measures the ability you intended. A title leaking the answer, absurd distractors, confusing grammar or broken OCR can change what the score measures.

    Leakage occurs when evaluation information reaches the model or your design process in a way that undermines the intended test. Sending the reference answer or explanation is direct leakage. Testing a short-answer companion after its MCQ in the same conversation also supplies a clue. Use fresh conversations.

    Development data is for choosing prompts, parsers and rubrics. Test data is held back for the frozen evaluation. The current CSV is marked unassigned_pilot. We have not claimed a held-out split. Related questions and repeated works should stay in the same split; a random row split can separate near duplicates.

    Balanced answer keys mean five A, five B, five C and five D answers in each field. This does not remove all position bias: repeat a development subset with alternative option orders to check sensitivity. The question wording, distractor quality and answer parser still matter. Read the option-order study.

    For user-facing answers, evaluate instruction/chat models with their supported templates and a recorded generation policy. Base models remain useful for the separate adaptation audit. Score generated answers for the user-facing track; next-token letter probabilities can disagree with the model's actual response. Read the generated-answer study.

    How should we grade a short answer?

    If the question requests «құлақ қошқары», a response giving only “cochlea” identifies the modern concept but misses the requested historical expression. If the question asks what the historical expression means, “cochlea” may be sufficient. The wording defines the grading target.

    accepted_answers_json helps with known variants. It is not an exhaustive list of every correct paraphrase. Human semantic grading is needed for explanations. Establish a rubric before looking at model performance, blind model identity, and adjudicate disagreements.

    How much can we infer from 20 items per field?

    One changed answer moves a field score by five percentage points. Small gaps can reflect question selection and source clustering. Report counts, paired differences and uncertainty. The two formats of a pair are not independent; several concepts on the same page can also be related.

    The fields also have different task mixtures. Linguistics is mainly historical-term recall, while pedagogy includes explanations. A field difference cannot be attributed to discipline alone. The geometry section does not cover all mathematics.

    A paired bootstrap resamples the same units for both models. For this collection, choose source/concept clusters carefully rather than treating every prompt as independent. Read the bootstrap foundations.

    5 · Your first independent contribution

    Build and defend three new pairs

    1. Choose a different source section in one field. Find three definitions or explicit explanations.
    2. Write the questions and reference answers before querying any model.
    3. Save exact evidence and distinguish original author, translator and edition.
    4. Write three plausible distractors for each target. Check that only one answer is supported.
    5. Ask another reader to answer without seeing your key, then inspect the source together.
    6. Explain each disagreement. Revise the item or mark it uncertain.
